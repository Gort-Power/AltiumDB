# AltiumDB
AltiumDB — Altium Designer component database manager.
You can manage component database, browse symbols, footprints and edit addition fields.


## How to work with this?

First of all you need to download and install ODBC connector for your database.
You can find it [there](http://www.ch-werner.de/sqliteodbc/sqliteodbc.exe) and [for x64 system](http://www.ch-werner.de/sqliteodbc/sqliteodbc_w64.exe).

Than you need to add ODBC data source for your system version. Just write in windows search "ODBC" and choose variant which match with yous system version.
Next step is adding "User DSN". Click "Add" button and choose your database driver, for example SQlite3 ODBC driver. In opened window you need to write data source name, which your you want, and pick your database file. Thats all!

After set database connection you need to install this program, you can find it in"Release". Download, install and run.

When software is started first time, you need change settings.

## Database backends

The application supports both SQLite and PostgreSQL. Select the backend in
**Settings -> Database type**:

- **SQLite** uses a local `.sqlite` file.
- **PostgreSQL** uses separate fields for host, port, database, user, and password.

The selected backend and connection settings are stored in the configuration
file next to the database. PostgreSQL tables are created and migrated
automatically in the selected database. Component data and custom fields are
stored directly in the selected database.

Use **File -> Import LCSC component...** to enter one or more LCSC part
numbers separated by commas. Spaces around commas are ignored. Categories are
detected from LCSC automatically; missing category tables and their available
secondary fields are created, while existing category schemas are preserved.
Existing components are updated. Components are written directly to the
selected database; no intermediate XLS file is required. The import uses
LCSC's current web JSON endpoint, which is unofficial and may be changed or
rate-limited by LCSC.

Settings also provide a full-path **Default Symbol** and **Default Footprint**
file. They are applied to newly added components and to direct LCSC imports when
the corresponding fields are missing from the imported row. The application
writes the file name without extension to the component's Ref field and the
matching library path to its Path field.

Symbol and footprint previews are generated by the external
[Altium Monkey](https://github.com/wavenumber-eng/altium_monkey) Python
package. Python and the package must be installed and available as
`python`/`altium_monkey` on the system PATH.

The Windows installer checks these prerequisites before allowing installation
to continue. If Python is missing, it opens the official Python download page.
If `altium_monkey` is missing, the installer offers to install it from the
official GitHub repository and verifies the import before continuing.
